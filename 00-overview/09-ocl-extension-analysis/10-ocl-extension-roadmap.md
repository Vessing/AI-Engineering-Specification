# OCL Extension Roadmap

## Zweck dieser Datei

Diese Datei soll die priorisierten OCL-Erweiterungen in technisch aufeinander aufbauende Post-MVP-Ausbaustufen überführen. Sie soll später Abhängigkeiten entlang der gesamten OCL-Pipeline sowie notwendige Anpassungen an Backend, API, Validation Flow, Library-Beispiel und Tests bündeln.

Status: Struktur angelegt; die Roadmap-Ausarbeitung folgt nach Freigabe.
