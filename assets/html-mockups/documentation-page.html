Welcome to USE Web

USE (UML-based Specification Environment) is a powerful tool for modeling and analyzing software systems using the Unified Modeling Language (UML) and the Object Constraint Language (OCL).

Originally developed as a Java-based desktop application, USE Web brings these capabilities directly to your browser with a modern, intuitive interface. It allows developers, analysts, and students to validate software designs early, ensuring conceptual integrity long before any production code is written.

Core Concepts

The USE workflow revolves around three main pillars that allow you to specify and test your models interactively:

1. Structural Modeling (Class Diagram) Define the blueprint of your system. You create Classes, define their Attributes and Operations, and establish structural relationships via Associations and Generalizations.
2. Instantiation (Object Diagram) Create concrete "Snapshots" of your system at a specific point in time. This involves instantiating Objects from your classes, setting specific attribute values, and connecting objects with Links based on your defined associations.
3. Constraint Validation (OCL) Write precise OCL invariants and pre-/post-conditions to enforce business rules. USE evaluates these expressions against your Object Diagram snapshots and instantly highlights any inconsistencies or violations.

Navigating the Documentation

Use the sidebar on the left to explore specific topics in depth. The documentation is organized by diagram type and feature, allowing you to quickly find details on specific panels, vocabulary, and UI controls.
