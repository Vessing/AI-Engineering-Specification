Responsive Regel

`Class Properties` öffnet als intern scrollbar bleibender Drawer. Die Featuresegmente bleiben oben erreichbar; Liste und Detaileditor werden nacheinander dargestellt.

Das Umschalten zwischen Attributes und Operations wechselt nur den Featureinhalt. Klasse, Auswahl und Diagrammkontext bleiben erhalten.

Annotationen

BereichFestlegung
Hauptnavigation`Class`, `Association` und `Invariant` bleiben gleichrangige Hauptsegmente.
Class Features`Attributes`, `Operations` und `Generalizations` liegen innerhalb von `Class`; sie sind keine neuen Workspace-Seiten.
NotationAttribute und Operationen besitzen ein eigenes UML-Kompartiment und verwenden `+`, `−`, `#` oder `~`.
AuswahlCanvas, Explorer, Featureliste und Detaileditor zeigen dasselbe ausgewählte Feature.
InvocationDie Class-Ansicht speichert nur Signaturen. Runtime Invocation bleibt im Object Diagram.
