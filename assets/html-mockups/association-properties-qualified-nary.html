Responsive Festlegung

Explorer und Properties werden nicht neben den Canvas gequetscht. Das ausgewählte Element öffnet einen intern scrollbar bleibenden Drawer. End-Namen ersetzen räumliche Begriffe wie „links“, „rechts“, „Source“ oder „Target“.

Auf kleinen Viewports bleibt der Canvas sichtbar; umfangreiche End- und Qualifierlisten verschieben das Diagramm nicht.

BereichFestlegung
EndmodellAssociation Ends werden als geordnete, dynamische Liste bearbeitet. Source/Target bleibt nur eine binäre Darstellungsabkürzung.
QualifierQualifier gehören zu genau einem Association End und besitzen Name, Typ und stabile Reihenfolge. Konkrete Werte gehören zum Object Link.
n-äre NotationEin benannter zentraler Association-Knoten verbindet mindestens drei Ends. Rollen und Multiplizitäten stehen an den Klassifierenden.
Sicheres LöschenVor dem Entfernen eines Ends zeigt die Bestätigung betroffene Links, Rollen und OCL-Verwendungen.
