Workflow and Scope

DecisionBehavior
Entry points`+` beside Classes, Add Class toolbar action or canvas context action opens the same dialog. A canvas action may provide the initial node position.
Required inputOnly `Class Name` is mandatory. Namespace, public visibility and concrete class are safe defaults.
Initial featuresThe existing frontend capability for initial attributes and operations remains available. The modal captures only compact signatures.
Deferred editingAttribute multiplicity, derived/default expressions, operation parameters, generalizations, invariants and contracts are edited after creation in their established Class Properties tabs.
SuccessThe modal closes, the class appears at the requested/default position, Explorer updates, the new node is selected and `Class Properties · Details` opens.
ValidationFrontend checks required fields. Backend remains authoritative for uniqueness, namespace resolution and feature/type semantics.
