Workflow and UML/OCL Scope

DecisionBehavior
Entry pointsCreate Invariant in Invariant Properties and an Invariants explorer action open this same modal. The selected class predefines the context.
Required inputA context classifier and OCL expression are required. The constraint name is optional in OCL but recommended for diagnostics and navigation.
SemanticsThe expression is compiled with self typed as the selected context and must conform to Boolean.
No invented notationCreating an invariant does not add a proprietary node to the diagram canvas. Optional diagram rendering must use supported UML constraint notation.
Validation boundaryThe modal performs syntax and static type checking. Check Constraints evaluates the saved invariant against object snapshots.
SuccessThe modal closes, Explorer and Invariant Properties refresh, and the newly created invariant becomes selected.
